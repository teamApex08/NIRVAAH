# Components

Reusable frontend components live here.

- `landing/`: landing page components and `landingData.js`.
- `command-centre/`: Command Centre components and `commandCentreData.js`.
- `projects/`: Projects page components and `projectsData.js`.
- `ui/`: small primitives such as buttons, cards, pills, and metric cards.
- `layout/`: page and dashboard layout shells.
- `navigation/`: app navigation components and navigation data.
- `shared/`: brand and cross-page presentation components.
